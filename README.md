# Dishly

A professional cooking and recipe discovery app built with .NET 10 WPF.

## Vision

Dishly is designed around a single premium visual identity: warm kitchen tones, deep natural surfaces, subtle motion, and focused cooking workflows.

## Planned features

- Recipe discovery and categories
- Search by recipe and ingredient
- Favorites
- Shopping lists
- Cooking mode with step-by-step guidance and timers
- Personal recipes
- Professional animated UI and micro-interactions

## Run

```powershell
dotnet restore
dotnet run --project .\Dishly\Dishly.csproj
```
